# 베라짐 움직임 패턴 확장 트리 — 제작 명세

## 목적
회원이 운동을 하나씩 외우기보다 공통 움직임을 배우고, 도구와 세부 변형으로 지식을 확장하는 상담용 웹앱이다. 태블릿에서 직접 가지를 눌러 탐색하고, 운영자는 코드를 수정하지 않고 분류와 설명을 편집한다.

## 합의한 사용 흐름
- 첫 화면에는 상체와 하체만 표시한다.
- 상체 → 밀기·당기기, 하체 → 스쿼트·힌지·런지로 펼친다.
- 예시: 상체 → 당기기 → 로우 → 바벨 → 바벨 벤트오버 로우.
- 깊이나 단계 이름은 고정하지 않는다. 도구 앞뒤에도 분류를 추가할 수 있다.
- 처음에는 합의한 대표 패턴과 로우 예시를 넣고, 운영자가 계속 확장한다.
- 같은 패턴의 변형은 실선, 관련 보조운동은 점선으로 표시한다. 점선 연결은 소속 경로에 포함하지 않는다.
- 부모를 접으면 자손을 숨긴다. 루트끼리는 독립적으로 펼칠 수 있다.

## 상담 화면
- 흰 배경의 캔버스 위에 카드와 연결선을 배치한다.
- 가지 클릭 시 아래 방향으로 자식 가지가 펼쳐진다. 이미 펼친 가지는 접힌다.
- 개별 운동을 선택하면 이미지와 설명을 보여주는 상세 패널을 연다.
- 이미지, 운동 이름, 소속 경로, 이름 풀이가 핵심이다. 빈 필드는 보이지 않는다.
- 소속 경로는 부모 관계에서 계산한다. 이름 변경이나 이동에 자동 갱신된다.
- 소속 경로의 각 이름은 칩으로 표시하고, 카드 너비에서 칩 단위로 줄바꿈한다. 매우 긴 이름은 칩 내부에서도 넘치지 않게 줄바꿈한다.
- 상담 모드에서는 편집 버튼을 숨긴다.

## 화면 이동
- 가지를 펼치거나 접을 때 현재 보이는 카드와 연결선 전체가 들어오도록 배율과 중심을 부드럽게 조정한다.
- 직접 확대하거나 이동하는 동안 자동 맞춤이 개입하지 않는다.
- 두 손가락 확대·축소, 빈 공간 드래그 이동, 마우스 조작을 지원한다.
- 전체 보기, 선택 가지 보기, 확대, 축소 버튼을 제공한다.
- 편집 중 텍스트 입력과 패널 스크롤을 캔버스 이동으로 해석하지 않는다.
- 버튼 터치 영역은 최소 44px로 유지한다. 화면 폭이 좁으면 상세·편집 패널을 하단 또는 전체 너비로 배치한다.

## 편집
- 가지 추가, 이름 변경, 형제 순서 변경, 다른 부모로 이동, 삭제, 실행 취소를 제공한다.
- 이동은 터치하기 쉬운 부모 선택 방식으로 제공한다. 자신의 자손 아래로 이동은 차단한다.
- 하위 항목이 있는 가지 삭제는 함께 지워질 개수를 표시하고 확인한다.
- 열매 등록: 운동 이름만 필수. 소속 가지는 추가 위치에서 자동 지정한다.
- 이미지는 여러 장 등록하고 대표 이미지와 순서를 선택한다.
- 이름 풀이는 단어·뜻 쌍을 원하는 수만큼 추가한다.
- 추가 설명은 제목과 본문을 자유롭게 추가·삭제한다. 숨김 항목은 데이터를 보존하고 상담 화면에서만 감춘다.
- 핵심 표시 항목도 이미지·경로·이름 풀이 표시 여부를 설정할 수 있다. 편집 화면에서는 다시 켤 수 있다.
- 가지에도 이미지와 설명을 넣을 수 있다.

## 이미지
- 기존 Supabase exercise-images의 공개 이미지는 URL로 연결하며 복제·수정·삭제하지 않는다.
- 기존 운동 목록의 이름과 image_url을 읽어 검색 가능한 선택 목록을 만든다. 기존 RPC의 익명 접근이 허용되지 않으면 공개 이미지 경로 목록을 최초에 정적으로 생성한다. 기존 권한은 변경하지 않는다.
- 이미지 선택 목록은 썸네일을 지연 로딩하고 검색 결과를 나눠 표시한다. 1,200개 파일 전체를 한 번에 내려받지 않는다.
- 새 이미지 업로드는 트리 전용 저장소를 사용하고, 기존 수업 사진 등 다른 버킷은 사용하지 않는다.
- 새 이미지 긴 변은 최대 1,600px로 제한하며, 투명 이미지의 투명도를 유지한다. 원본보다 커지는 변환은 적용하지 않는다.
- 카드에서 이미지 제거는 연결만 해제한다. 공유 원본 파일을 자동 삭제하지 않는다.

## 테마
- 빨강·주황·노랑·초록·파랑·남색·보라의 일곱 테마를 제공한다. 기본은 초록이다.
- 설정에서 하나를 선택하면 트리 전체에 적용하고 다른 기기에도 동기화한다.
- 화면, 가지 버튼, 카드, 설명 영역의 배경은 흰색이다.
- 테마 색은 테두리, 연결선, 표시 아이콘과 기능 버튼 강조에 사용한다.
- 선택 항목은 테두리를 굵게 한다. 본문은 짙은 중립색이며 노랑 테마도 가독성이 확보되는 어두운 선 색을 쓴다.

## 저장과 기기 간 동기화
- 사용자 요청에 따라 회원가입·로그인·사용자별 계정 관리를 만들지 않는다.
- 기기 공유용 개인 링크로 같은 트리를 연다. 이 링크를 가진 사람은 편집할 수 있다는 기존 합의를 따른다.
- 기존 Supabase에 트리 전용 데이터 테이블과 이미지 버킷을 추가한다. 기존 회원·일정·수업 데이터와 정책을 수정하지 않는다.
- 브라우저에는 공개 클라이언트 키만 사용한다. 관리자 키는 배포 파일에 넣지 않는다.
- 편집 내용은 먼저 기기에 보관하고, 마지막 입력 후 1초 뒤 변경 묶음을 저장한다. 저장 중·저장됨·오프라인·충돌 상태를 표시한다.
- 페이지 진입·다시 활성화·수동 새로고침 때 서버 버전을 확인한다. 화면이 보일 때만 60초 간격의 작은 버전 조회를 허용한다. 편집하지 않은 데이터는 서버에 쓰지 않는다.
- 버전 번호를 조건으로 원자적으로 저장한다. 다른 기기의 수정과 충돌하면 로컬 내용을 보관하고 비교 선택을 요청한다. 자동으로 덮어쓰지 않는다.
- 서버 연결 실패 시 마지막 기기 저장본으로 열고 미동기화 표시를 유지한다. 실패를 빈 트리로 취급하지 않는다.
- 백업 내보내기·가져오기를 제공한다. 백업에는 트리와 참조 이미지 파일을 포함하고, 복원 전 구조와 이미지 무결성을 검사한다.

## 완료 기준
1. 상체·하체에서 시작해 클릭할 때마다 올바른 자식 가지가 나타난다.
2. 긴 경로와 한국어 이름이 겹치거나 카드 밖으로 넘치지 않는다.
3. 전체 보기·핀치·드래그·선택 가지 보기와 자동 맞춤이 태블릿 크기에서 작동한다.
4. 가지 추가·이동·삭제·취소 뒤 계층이 올바르고, 잘못된 순환 구조를 허용하지 않는다.
5. 이미지 선택·삽입, 이름 풀이와 추가 필드 표시 설정이 저장 후 유지된다.
6. 두 독립 브라우저 환경에서 트리와 테마가 동기화되며 동시 저장 충돌을 안전하게 처리한다.
7. 네트워크가 끊겨도 로컬 편집이 남고, 백업·복원이 정상 동작한다.
8. 배포 산출물에 관리자 키가 없고 기존 회원 앱에는 변경이 없다.
