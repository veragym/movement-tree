# Movement Atlas · 베라짐

태블릿 상담용 움직임 확장 트리. https://veragym.github.io/movement-tree/

처음에는 상체와 하체만 보입니다. 가지를 눌러 펼치고, 오른쪽 위 편집 버튼으로 가지·운동·사진·이름 풀이를 수정합니다. 설정에서 테마와 백업을 관리합니다.

## 동기화 연결

Supabase SQL Editor에서 `supabase/setup.sql`을 한 번 실행한 뒤 앱 설정의 ‘연결 확인’을 누릅니다. ‘클라우드 저장됨’을 확인한 후 ‘개인 링크 복사’로 복사한 주소를 다른 기기에서 여세요. 주소의 `#tree=...` 부분까지 같아야 같은 트리가 열립니다. 개인 링크를 가진 사람은 편집할 수 있습니다. 별도 로그인은 없습니다.

설정 전에는 이 브라우저에만 저장됩니다. 다른 기기로 옮기기 전에는 백업을 내보내세요. 연결이 끊긴 동안 열린 앱에서 편집한 내용은 기기에 보관되며, 재연결 시 다른 기기의 변경 사항과 충돌하면 선택 창을 띄웁니다. 오프라인 상태에서 앱을 처음 여는 기능은 제공하지 않습니다.

## 데이터 원칙

- 제공 자료에서 57개 운동 이름만 후보 목록으로 사용했습니다. 원본 분류·계층·설계는 가져오지 않았습니다.
- 기존 운동 이미지 1,195개는 URL로 연결합니다. 이미지 원본을 복제하거나 변경하지 않습니다.
- 기존 회원 앱과 별도 저장소/사이트/테이블/이미지 버킷을 사용합니다.
- 설정에는 공개 publishable 키만 포함됩니다. 관리자 키는 사용하지 않습니다.

## 개발 및 검증

`npm ci`, `npm test`, `npm run build`, `npm run dev`.

모델 테스트 7개 통과. 실제 Edge 화면에서 가지 확장, 운동 추가, 이미지 선택, 이름 풀이, 숨김 항목, 테마, ZIP 내보내기 및 다양한 화면 폭을 검증했습니다. 모의 서버로 동시 수정 충돌, 지연된 응답 중 저장, 연결 복구, 기기 저장소 장애, 사진 처리 중 편집 유지를 검증했습니다.

배포 주소에서 초기 두 가지와 상체 확장을 확인했습니다. 실제 Supabase 동기화는 전용 SQL이 아직 적용되지 않아 검증 대기 상태입니다.
