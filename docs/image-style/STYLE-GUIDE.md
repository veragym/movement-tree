# 운동트리 인체 일러스트 기준 v2

사용자 승인: 2026-10-22. 이 문서는 시각적 인체 모델과 색채 기준입니다. AI 엔진의 특정 모델 버전·seed·캐릭터 ID가 제공된 것은 아닙니다.

## 기준 이미지
- reference-push-family.png: 최종 승인된 밀기 계열 이미지. 인체·색채·표현의 우선 기준.
- reference-press.png: 최초 승인된 동일 인체 스타일. 두 자세를 표현할 때의 투명도 참고.
- 원본은 변형 없이 보존합니다. 신규 이미지는 다른 파일명으로 저장합니다.

## 고정할 인체
- 얼굴 이목구비와 머리카락이 없는 매끈한 회색 근육형 인체.
- 단단한 체형, 자연스럽게 구분되는 가슴·어깨·팔 근육, 기준 이미지와 같은 신체 비율.
- 실사 인물이 아닌 부드러운 입체 교육용 일러스트. 과장된 혈관·근섬유·피부 없는 해부도 금지.
- 무광에 가까운 밝은 회색 몸체, 부드러운 회색 음영, 짙은 차콜 반바지.
- 주요 부위만 옅은 코랄로 강조. 나머지 근육은 회색 유지.
- 동일 인물처럼 보이도록 머리 형태·어깨 폭·근육량·음영 강도를 유지.

## 색채 기준
기준 이미지의 실제 색감이 아래 근사 HEX보다 우선합니다. 아래 값은 재제작용 목표색이며 픽셀에서 추출한 값은 아닙니다.
- 배경: 순백 #FFFFFF
- 몸체 밝은 톤: #D9D9D9 / 중간 음영 #B3B3B3
- 반바지·기구: 차콜 #454545
- 주요 근육 강조: 옅은 코랄 #EE9B91 (과도하게 붉거나 진하게 하지 않음)
- 방향 화살표: 보라 #7041ED, 단색·불투명. 이미지 내 라벨 없음
- 앱 테마가 바뀌어도 이 이미지 팔레트를 자동으로 바꾸지 않습니다. 사용자가 요청할 때만 변경합니다.

## 구성 규칙
- 이미지 크기는 고정하지 않습니다. 실제 트리 카드 이미지 틀을 확인한 뒤 캔버스 비율을 맞춥니다.
- 인체를 가로세로로 늘이지 말고 여백과 배치를 조정합니다. 손·팔·화살표가 잘리지 않게 합니다.
- 상위 범주: 대표 동작을 같은 비율로 나란히 배치. 동작당 인체 1개와 명확한 화살표.
- 개별 동작: 필요할 때 시작 자세는 연하게, 끝 자세는 진하게. 두 자세가 복잡하게 겹치지 않게 간격 유지.
- 상체 동작은 상체 중심, 하체 동작은 골반·다리와 필요한 몸통까지 보여줍니다.
- 흰 배경, 최소한의 기구. 이미지 내 글자·숫자·라벨을 넣지 않습니다. 로고·워터마크·장식 테두리 없음.
- 화살표는 해당 관절의 실제 이동 방향을 표시합니다. 서로 다른 동작을 같은 밀기 화살표로 통일하지 않습니다.
- 밀기 계열 그림은 앱 분류 안내이며, 플라이·레이즈가 모두 생체역학적으로 같은 프레스라는 뜻이 아닙니다.

## 이후 생성 절차
1. 이 문서와 기준 PNG를 읽고 이미지를 시각적으로 확인합니다.
2. 이미지 생성 도구에 reference-push-family.png를 스타일 참조로 첨부합니다. 두 자세 표현이 필요하면 reference-press.png도 함께 참조합니다.
3. reusable-prompt.txt를 사용하고 동작·시점·기구·캔버스 비율만 변경합니다.
4. 얼굴·체형·색채·질감·손가락·관절·화살표를 비교 검사합니다. 차이가 크면 기준을 다시 첨부하여 수정합니다.
5. 사용자가 트리 연결을 요청하기 전에는 시안으로 보관합니다.

생성형 이미지 특성상 완전히 동일한 픽셀이나 인체를 보장할 수는 없습니다. 텍스트만 재사용하지 않고 승인 이미지를 매번 함께 참조하여 일관성을 높입니다.

## 2026-10-23 확정 변경 — 텍스트 제외 및 화살표 규격
- 새 이미지는 글자 없이 생성합니다. 이름은 트리 카드의 실제 텍스트로 표시합니다.
- 상체·하체 최신본: drafts/upper-body-v2-no-text.png, drafts/lower-body-v2-no-text.png.
- 기존 reference 이미지의 텍스트·화살표 굵기는 과거 시안입니다. 인체와 색감만 참조하며 아래 규격이 우선합니다.
- 화살표는 필요할 때만 사용합니다. 상체·하체 부위 안내에는 넣지 않습니다.
- 최종 이미지 높이 H 기준 선 두께 = H × 0.008, 화살촉 길이 = H × 0.028, 화살촉 전체 폭 = H × 0.024.
- 기준 H=1000일 때 선 8px, 화살촉 길이 28px, 폭 24px. 동일한 표시 높이에서 모든 이미지의 굵기와 화살촉 크기가 같도록 유지합니다.
- 색 #7041ED, 불투명도 100%, 채운 이등변 삼각형 화살촉, 선 끝·꺾임 둥글게. 그라데이션·원근 축소·그림자 없음.
- 직선/곡선, 선 길이, 회전각만 달라질 수 있습니다. 곡선에서도 선 두께와 화살촉 크기는 바뀌지 않습니다.
- arrow-standard.svg와 arrow-spec.json을 동일한 기준 자산으로 사용합니다. SVG의 viewBox 높이는 1000입니다.
- 생성 도구의 프롬프트만으로 정확한 치수 일치를 보장할 수 없으므로 최종 이미지와 카드 표시 높이에서 반드시 비교합니다. 정확한 통일이 필요한 최종 제작은 동일한 벡터 화살표 자산을 사용합니다.

## 관절 설명 이미지의 손잡이 기준
- 근육 강조 없이 회색 인체, 움직이는 관절만 보라색으로 표시.
- 프레스: 정측면 자세, 양손 수평 그립. 양팔이 자연스러운 깊이 차이로 구분되도록 표현.
- 플라이: 양손 수직 그립. 푸시다운: 양손 수평 그립.
- 모든 손잡이는 원판 없는 차콜 원통형. 손에 닿는 부분의 길이와 지름을 같은 손 크기 대비 동일하게 유지.
- 기준 손잡이 길이는 손바닥 너비 약 1배, 지름은 약 0.2배. 수직/수평 방향만 변경.

## 관절 분류용 상체 이미지의 크롭 변경
- 밀기 복합관절·단일관절은 머리부터 배꼽까지 표현합니다. 골반·반바지·허벅지를 넣지 않습니다.
- 몸통 하단은 배꼽 부근에서 흰 배경으로 부드럽게 사라지게 합니다. 동작 설명에 필요한 손·그립은 모두 보존합니다.
- 프레스 시작 자세는 양팔꿈치가 굽혀져 몸통 양옆으로 벌어진 모습입니다. 손만 들어 올린 컬 형태로 그리지 않습니다.
- 프레스 시점은 사용자가 제시한 양손이 잘 보이는 정면 사선 참고본을 우선합니다.
