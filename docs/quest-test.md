# Movement Quest 테스트판

- 주소: /quest.html
- 기존 앱 진입점(index.html), 트리 편집 기능과 데이터는 유지합니다.
- 테스트 저장 키: 640122aa-9d3d-4ec0-af7c-c7d4a17f7f25
- 원본 키와 다른 문서로 복사하여 20개 예시 퀘스트를 구성했습니다.
- 5대 패턴 핵심 퀘스트 + 패턴별 대표 운동 3개. 원본 운동 노드는 복사본 안에 보존하고 퀘스트 화면은 정의된 항목만 표시합니다.
- 학습자 별 배정/체크/상태/최초달성일/최근확인일/메모/달성기록을 저장합니다.
- 필수 조건 완료 후 코치 확인으로 달성 처리, 선행 퀘스트 달성 또는 코치 직접 열기로 진행합니다.
- 최초 달성일은 재점검 후에도 보존합니다. 현재 달성률은 배정된 목표 중 현재 달성 상태인 비율입니다.
- 조건 편집은 테스트판 회원 공통입니다. 새 필수 조건을 충족하지 못한 기존 달성은 재점검으로 전환됩니다.
- 전용 로그인은 없으며 테스트용 별칭만 사용합니다. 실제 회원 시스템과 연결하지 않습니다.
- CAS 버전 확인 및 충돌 UI, 기기 보관/클라우드 저장은 기존 동기화 모듈을 사용합니다.
- 검증: 23개 단위 테스트, 브라우저 달성/해금/회원분리/조건편집/새로고침 유지, 태블릿 폭 확인.
