- 평가 항목 추가/수정/삭제, 가지에서 드롭다운 선택 및 연결/해제, 학습자 추가/수정/삭제를 지원합니다.

- 새 조건 추가 시 현재 달성은 미달성으로 바뀝니다. 최초 달성일은 유지합니다.

- 달성률은 조건이 연결된 가지 수 기준입니다. 잠금·선행 조건·경험치는 없습니다.
- v1의 학습자 이름만 가져왔습니다. 복잡한 예시 달성 기록은 이전 문서와 로컬 백업에 보존됩니다.
- 기존 동기화 모듈 사용: 기기 저장, 클라우드 CAS, 충돌 선택. 새로운 로그인/회원 시스템 연동 없음.
