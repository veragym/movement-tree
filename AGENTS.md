# Movement Tree project instructions

## Exercise illustration requests
When creating or editing exercise illustrations for this project, read `docs/image-style/STYLE-GUIDE.md` first and visually inspect its reference images. Use the approved faceless grey muscular mannequin, pale coral muscle highlights, charcoal shorts and purple arrows (no baked-in text). Attach the reference image to generation calls; text-only restyling is insufficient. Use `docs/image-style/reusable-prompt.txt` as the prompt base. Fit the current tree image frame without stretching the body. Preserve reference originals. Do not connect preview assets to the live tree unless the user requests it.

All new images must contain no text. Use docs/image-style/arrow-spec.json and arrow-standard.svg for consistent shaft thickness and arrowhead size, scaled by image height. The older reference images are character/palette references only; their lettering and varied arrow sizes are superseded.
