# 기초 퀘스트 최초 배치표

원본 72개를 70개 평가 항목으로 정리했습니다. 66개는 가지에 배치하고, 4개 회전 항목은 평가 목록에 보관했습니다. Q048은 Q042, Q071은 Q033에 통합했습니다.

## 적용 원칙

- 상체·하체에서 공통 기초를 먼저 배우고, 패턴·동작군·방향 순으로 새 조건만 추가합니다.
- 같은 경로의 상위·하위에 동일 조건을 중복 배치하지 않습니다. 서로 다른 경로에서는 같은 평가 항목을 재사용합니다.
- 상체·하체는 별도 루트라 공통 조건이 각각 존재합니다. 한쪽 달성이 다른 쪽을 자동 달성시키지는 않습니다.
- 모든 노드에 새 퀘스트가 필요하지는 않습니다. 새 조건이 없는 방향·도구·운동은 상위 학습을 적용하는 단계입니다.
- 선행 달성으로 가지를 잠그지 않습니다. 공통 기초는 지도 항목이며 모든 하위 운동에서 동일한 관절 위치를 강제하는 조건이 아닙니다.
- 레그 컬·내전·외전 등 보조운동이 해당 패턴 동작이라는 뜻은 아닙니다.
- 기존 스트레이트 암의 밀기 단일관절·스쿼트·힌지 연결은 제거하고 플라이·레이즈·어깨 신전·후면 어깨 벌림에 배치했습니다. 기존 기록은 보관하고 새 위치를 자동 달성시키지 않았습니다. 동일 힌지 가지의 힙 힌지 기록만 Q033으로 연결합니다.
